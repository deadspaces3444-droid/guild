# ⚔️ Guild Site

Локальный сайт для управления списками гильдии. Работает без сервера и БД — данные хранятся в localStorage браузера.

## Запуск

Просто открой `index.html` двойным кликом. Всё.

## Пароль админа

По умолчанию: `guild123`
Меняется в `app.js` в объекте `CONFIG.password`.

## Возможности

- 4 вкладки: Враги / Друзья / Нейтралитет / Не трогать
- Гость видит списки, но не может менять
- Админ (после логина) может:
  - добавлять записи
  - удалять записи
  - перемещать записи между вкладками (кнопка ↔)

## ⚠️ Про хранение

Данные хранятся **в localStorage конкретного браузера**.
- Не синхронизируются между устройствами/браузерами
- Удаляются, если почистить кэш браузера
- Для резерва — скопируй JSON из DevTools → Application → Local Storage → `guild_lists_v1`
